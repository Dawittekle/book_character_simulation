# Lorely Brand Design Proposals (brand/text)

This folder contains the brand identity and logo redesign proposals created for Lorely.

Per user instruction, these assets are stored here for evaluation and **are not yet applied to the active application UI**.

## Files in this Folder

1. **`LOGO_REDESIGN_PROPOSALS.md`**: Comprehensive design document outlining the philosophy, geometry, and variants.
2. **`logo_preview.html`**: Interactive HTML viewer displaying Concept 1, Concept 2, and Concept 3 side-by-side on light, dark, and paper backgrounds.
3. **`concept_1_literary_rosette.svg`**: Open book core + 8 orbital nodes (Recommended).
4. **`concept_1_literary_rosette_white.svg`**: Pure white version for dark backgrounds.
5. **`concept_1_literary_rosette_dark.svg`**: Obsidian version for monochromatic printing.
6. **`concept_2_folio_petals.svg`**: Blooming book leaves with circular nodes.
7. **`concept_3_dialogue_octofoil.svg`**: Conversational dialogue quote seeds around chapter asterisk.
8. **`lockup_concept_1.svg`**: Complete horizontal lockup (Mark + "Lorely" Wordmark + Tagline).
